# Кубики & Карти — Розумна підписка на настільні ігри

Вебсервіс з підбору та підписки на настільні ігри з адаптивною семантичною формою зворотного зв'язку, клієнтською валідацією на Vanilla JavaScript та сучасним модальним вікном.

## 🚀 Технологічний стек
- **HTML5:** Семантична структура (`<form>`, `<label>`, `<input>`, `<textarea>`, `<button>`), атрибути доступності W3C ARIA (`aria-describedby`, `aria-invalid`, `role="dialog"`).
- **Tailwind CSS:** Mobile-first адаптивна верстка, системи станів (Normal, Focus, Error, Success).
- **Vanilla JavaScript (ES6+):** 
  - Динамічна валідація даних (`blur`, `input`, `submit`);
  - Регулярні вирази (RegEx) для валідації імені, email та строго українського формату телефону (`+380XXXXXXXXX`);
  - Обробка граничних випадків (Edge Cases) для номера телефону;
  - Доступне модальне вікно успішного надсилання (підтримка `Escape`, клік по оверлею, фокус).

## 📋 Структура форми
- **Ім'я:** обов'язкове, від 2 символів, підтримка кирилиці та апострофа.
- **Email:** обов'язкове, перевірка структури `user@domain.tld`.
- **Номер телефону:** обов'язкове, формат `+380XXXXXXXXX` (9 цифр після +380).
- **Тема звернення:** селект для вибору теми повідомлення.
- **Повідомлення:** обов'язкове, мінімум 10 символів.
- **Згода:** обов'язковий чекбокс згоди на обробку даних.
